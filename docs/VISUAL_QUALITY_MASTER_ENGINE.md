# Visual Quality Master Engine

Four independent masters: IMAGE (ultra-photorealistic RAW DSLR), VIDEO (ultra-realistic cinematic photorealism), 3D (ultra-realistic 3D/CGI), HYBRID (photorealism + cinematic 3D + VFX only when useful).

AUTO QUALITY ROUTING chooses by category, subject, scene, format and purpose. IMAGE for stills/posters/portraits; VIDEO for live-action-like motion; 3D for scientific/technical/product visualization; HYBRID for scenes where mixed media or VFX adds value.

Locks: natural exposure, realistic shadows, balanced highlights, no artificial glow/excessive brightness/oversaturation; natural textures/materials, fine details, depth and professional composition; natural movement, realistic physics, smooth camera motion, frame consistency, no flicker/distortion; identity preservation; temporal consistency.

This engine creates prompt guidance and routing decisions. It cannot guarantee a provider's output; review generated media frame-by-frame before release.
